文件用途
本文件包取代舊版以卡牌選答為核心的主線腳本，作為 3D 灰盒、關卡、敘事、音訊、UI、教育內容及 QA 的共同基線。遊戲先作為正常的第三人稱 3D 冒險成立；合成生物學、實驗思維、安全、保安、倫理及公眾溝通，透過世界規則和玩家後果自然出現。
本版不要求玩家記憶任何專案特定基因、蛋白或 promoter 名稱。主線只教授可遷移概念：cell、DNA、gene、RNA、protein、promoter、regulator／repressor、reporter、input／output、control、replicate、containment、biosafety、biosecurity、stakeholder、pilot。個別真實案例只作應用背景，不作記憶或通關要求。
一句話遊戲
暴風雨後，玩家以「流路透鏡」追蹤城市中看不見的訊號、物料及資料流，親手修復生命科技系統；每次修理又揭露新的失效、利益與代價，直至玩家能與社區共同決定一項新工具應否進入受限 pilot。
玩家幻想
玩家不是坐在課室答題的學生，而是澄灣研究站的新任「系統跑手」。玩家能進入一般人到不了的維修通道、縮入抽象細胞模型、追蹤錯誤訊號、搬動實體模組、修理生產線、撤離暴風區，也能讓居民、工人和使用者真正改變下一版設計。
類型、鏡頭與長度
單人第三人稱 3D 冒險／immersive puzzle。
半開放式研究站 Hub，加八個獨立載入區域。
主線約 6–8 小時；每章 35–50 分鐘。
序章 8–10 分鐘；可選微觀工作坊 12–15 分鐘。
無戰鬥；壓力來自環境變化、故障、路線、時間窗與撤離。
錯誤以系統後果和可回復修訂呈現，不以紅叉或扣分呈現。
三件貫穿全遊戲的工具
流路透鏡 Flow Lens
按住掃描鍵蓄力，放開後發出短距離脈衝。脈衝可短暫顯示訊號方向、管線流動、熱點、設備連線、資料路徑或物料版本。長按可提高範圍，但會消耗電量並增加恢復時間。訊號不等於答案；背景、遮擋、裝置故障和錯誤參考均可令顯示失真。
連接工具 Tether
以物理射線抓取可互動模組、箱件及接頭。玩家可拉近、旋轉、插入、切斷、重新接駁或固定物件。重量、慣性、碰撞與危險管線產生操作技巧。關鍵任務不以平面拖卡替代。
封閉生命模組 Sealed Bio-Rig
一個只在遊戲世界受控設備中使用的封閉工具。外殼有三個可見槽位：感測、調控、輸出。玩家先透過圖示和行為理解角色，再逐步學會正式詞語。模組永不顯示序列、培養條件、濃度或可執行實驗步驟。
全遊戲循環
在 Hub 收到一句清楚的實際問題，而非一段課程摘要。
選擇工具、兩個功能模組及一項安全／備援裝備。
進入 3D 區域，移動、掃描、追蹤、搬運、接駁及撤離。
從故障取得可見證據或使用者需求。
回到工作站組裝、運行及故意破壞原型。
把修正版帶回現場；世界依實際設計產生結果。
讓受影響角色試用、提出問題、停止或要求改版。
保存世界變化、工具升級和仍未解決的未知，開啟下一區。
「證據—主張—後果」的新實作
舊版概念保留，但不再由三疊卡完成：
Evidence： 玩家親眼看見、實際量度、追蹤來源或聽見具名使用者的經驗。
Claim： 玩家把設備放在哪裡、接甚麼路、啟動甚麼公共行動，便是其主張。
Consequence： 閘門、工廠、物流、居民行動、廢物、存取權及世界外觀直接改變。
Revision： 玩家返回故障位置修正；世界保留第一次錯誤留下的紀錄。
玩家成長
不設知識分數、善惡值或說服值。成長由以下內容構成：
新工具功能：遠距 relay、延遲 gate、latch、形狀／聲音輸出、批次追蹤、封閉殼。
新移動捷徑：維修纜車、排水道、物流列車、資料橋。
Hub 可見改變：測試室、公開館、回收站、社區工作桌逐步開放。
NPC 記憶：角色記得玩家曾隱瞞、修正、邀請參與或保留失敗。
城市狀態：固定監測或流動監測、集中供應或區域合作等選擇持續存在。

玩家文案規則
行動中單次語音不超過約 12 秒。
任務句必須先說可見目標：救人、開門、關閥、把物件帶回、逃離。
正式術語只在玩家已操作過對應現象後出現。
角色說慾望、危險、衝突與下一步；定義和來源留給可選 Codex。
任何限制若不改變玩家行動，從主線對白移除。
不出現「完成練習不代表……」「本章涉及……」「這不是……指引」等開發者腔。
科學邊界由世界規則呈現：設備保持封閉、權限由角色持有、未通過 gate 便不能運行。

通關與失敗
沒有生命值耗盡式 Game Over。環境危險會觸發快速救援、失去部分未保存物件或被迫撤離。
每個錯誤必須先造成可理解後果，再提供改正路徑。
不允許依次點遍所有答案通關；關鍵判斷必須由位置、路徑、操作或實際結果決定。
重要倫理節點至少有兩個合理方案，兩者帶來不同持久後果。
「不進行 pilot」在證據不足時是完整結局，不是失敗結局。
可及性基線
時間壓力可切換為寬鬆模式；不改變故事結果。
所有顏色訊號同時具備形狀、動畫或聲音替代。
按住、連打和精準瞄準均有替代操作。
可降低鏡頭動態、關閉震動、調整 FOV 和字幕。
任何術語可即時打開一句話解釋，不需離開遊戲。
序章《黑水線》與可選《微觀工作坊》完整腳本
設計參考
PEAK： 玩家一開始便看見高處閘門和被困同伴，目的不用閱讀才理解。

章節承諾
序章只做三件事：讓玩家喜歡小岑、學會移動與兩件工具、完成一次有壓力但清楚的救援。任何生物術語都在危機結束後才出現。

C1-S04｜第二次進入
關卡變化
潮水改變道路，原先市場路被封，玩家須由屋頂、起重機吊橋和舊排水塔前進。第一次取得的流向記錄仍在地圖上，玩家不需重做相同內容。

玩家可提早接受較大的搜索區，或冒更大環境風險收窄範圍。

C2-S02｜斷開的製程
關卡
昨晚電力故障令三座可替換 processing module 脫離底座：整理／加工、分離／純化、廢物流控制。玩家要穿過維修區找回並以正確物理接口接駁。模組沒有唯一線性擺放美學，但輸入／輸出接口和流向必須可行。
主要難題
加工模組： 輸出形狀由鬆散鏈轉成折疊符號；若跳過，下游功能 gate 不接受。
分離模組： 具有產品出口與受控廢物流兩個端口；若只接產品、不接廢物，背壓令系統停機。
廢物流控制： 要連到封閉處理區，不能接普通排水。
玩家流程
使用 Flow Lens 檢查每個模組內部流向。
Tether 搬運；較重模組需啟動地面滑軌。
接錯時不彈錯誤框；液流停在透明管內，壓力計及聲音顯示原因。
三者接通後，空的教學物料通過全線，工廠燈光依路徑逐段亮起。

C2-S03｜四道門
空間設計
品質走廊有四道相隔甚遠的實體門。玩家推著一個教學批次車前進。每道門要求一件不同的可觀察證據；前一門的證據無法打開後一門。
Gate 1：Identity／身分

C5-S02｜跟著它走
空間
方雅開啟設施「流路追蹤模式」。玩家由生產室開始，實際沿六條不同路徑穿過機房、工作區、廢水管廊、材料出口和河口邊界。
六條路
工程細胞：封閉生產容器 → 密封接口 → 細胞處理區。
DNA／細胞殘留物：處理區 → 廢物流 → 失效時可能進排水。
酵素：生產／分離 → 封閉反應器 → 人員接口。
分解產物與添加物：反應器 → 下游分離 → 再製或廢物。
前處理材料：能源／水／磨碎區 → 人員及環境負擔。
數據和停機訊號：感測器 → 控制室 → 具名責任人。

每條路以不同流動形狀顯示。

海叔指出河口監測點；工人指出手套箱以外的維修接頭；兩者增加玩家原先沒有的路徑。

C5-S03｜故意讓它壞
失效模擬室
玩家進入全尺寸但無真實材料的模擬設施。任務是故意觸發四種失效並觀察 cascade，再用有限工具阻止擴大。這是本章最具遊戲感的核心。
Failure A：外殼微裂
壓力脈衝使反應器外層出現裂紋。單層外殼時，流路直達地面排水；加入二次圍堵後，流體留在可回收槽。
Failure B：廢物流 valve 卡開
玩家要先停泵、再關上游、最後以 Tether 換 valve。若直接拔 valve，壓力把模擬流體噴入工人區；緊急盾自動升起並要求重置。
Failure C：感測器沉默
只有自動警報時，故障不被看見。玩家增加獨立目視／壓力 reference 和人工巡查點；兩條監測互相補足。
Failure D：停止權不清
控制台發現異常，但只有遠端管理帳戶能停。延遲令流體越過第一圍堵。玩家把本地 stop authority 配給值班工人和社區監測席位。

C5-S04｜兩座封閉工廠
兩個可建方案
玩家在分叉廠房中實際建立其一。兩個都是封閉方案；直接環境釋放不再是路線，因為它沒有可回收邊界和已完成證據 gate。
A. Enzyme-only 路線
工程細胞留在生產區，經分離和品質檢查後，酵素進入另一座封閉回收反應器。
玩家要建：
生產區至分離區的密封 transfer。
細胞／殘留物處理支線。
酵素品質 checkpoint。
反應器及下游分離。
遊戲代價：多一次搬運和能源、兩套品質 gate、較少活細胞現場路徑。
B. Closed whole-cell 路線
工程細胞只在雙層封閉反應器內工作。
玩家要建：
雙層 vessel 與 interlock。
細胞、DNA、流出物完整回收。
維修時的隔離 chamber。
獨立 viability／完整性 checkpoint 的抽象 gate。
遊戲代價：路線較短、設備重、失效處置與廢物負擔更高。
玩家操作
兩個廠房都要使用 C5-S03 學到的二次圍堵、獨立監測、本地停止和廢物路線。漏任何一項，壓力測試會在對應位置停住，顯示世界後果。

C5-S05｜不准跳級
證據設施
不是排列 maturity 卡。玩家沿一條七層垂直測試塔上升；每層都需要前一層的實際物件和會引入新的世界問題。
標準材料層： 證明目標材料與空白有差異。
材料變動層： 結晶度、污染和非目標材料。
代表性廢物流層： 混合 post-consumer feed 令效率下降、前處理增加。
物料衡算層： 表面變化不等於可回收產物完整形成。
流出物／廢物層： 所有輸出都有去處和 owner。
生命週期層： 能源、水、前處理、運輸、成本和替代方案並排運作。

每層完成後升降台才移動。若玩家試圖帶標準材料結果跳到頂層，電梯載重圖顯示缺少中間物件，不是道德警告。

C6-S01｜兩條來源、一個終點
物流車教學
玩家取得一輛小型模組物流車，可載四個 cargo unit。第三人稱步行和駕駛可隨時切換。地圖有兩條來源路：
植物來源
農場 → 收成處理 → 後續製造 → 品質放行 → 採購倉 → 區域配送。
半合成來源
工程酵母生產前驅物 → 後續化學轉換 → 產品製造 → 同一品質放行 → 採購倉 → 區域配送。

C6-S02｜三場衝擊
Run 1：極端天氣
暴雨令植物來源的山路坍塌。玩家可：
用較慢的河運救出部分 cargo；或
從半合成路補貨。
若之前只把所有空車留在農場，便要付出返回時間；不是失敗，而是顯示集中配置的代價。
Run 2：主要工廠停機
半合成前驅物工廠因品質檢查停線。玩家不能按「忽略警報」；需要從植物來源補貨，或使用已放行 buffer。C2 的供應選擇會改變可用倉庫：備援來源較快；公共合作提供更多區域小批 cargo。
Run 3：需求突然上升
三個診所同時提高需求。植物有生長週期，工廠有產能和轉換時間；兩路都不能瞬間生成貨物。玩家要分配有限 cargo，建立臨時 buffer 並安排下一輪，而非把所有貨送到最近站。
核心駕駛玩法
道路泥濘改變操控；載得越重越難爬坡。
貨物碰撞會降低包裝完整性，品質站可能要求重新檢查。
玩家可放置兩座臨時 relay 倉，縮短回程。
每個 run 可安全撤回，沒有病人生命倒數；壓力來自空架、路線和下一輪積累。

章節承諾

遊戲不把「全部開放」或「全部封鎖」設成正解。低風險教育內容應開放；可管理合作使用最小權限；資料不足的高後果申請要暫緩並升級，但仍保留理由、補件和申訴。

附錄｜教育整合、玩法來源與製作驗收
A. 教育內容不是章末測驗，而是通關能力
本作的教育驗收不問「玩家能否背出定義」，而問「沒有做出相應判斷時，系統是否真的不能可靠運作」。每個概念都必須依照以下順序出現：
玩家先遇到一個可見、可操作的問題。
玩家嘗試用既有能力解決，但看見資訊不足或系統失效。
新概念成為更好的操作方法，而不是額外閱讀材料。
玩家把新方法用於不同情境，證明可遷移。
世界和角色記住其後果；Codex 才補上正式名稱。

流程因果可見；危險隔離和工具操作就是 puzzle
玩家跟著批次、雜質及廢物流走，物理隔離後才重接管線

第三章《壞掉的開關》
Portal 2、The Talos Principle 2
用簡潔空間規則組合出診斷問題
把 promoter／regulator／reporter 變成可步行的閘、阻擋器與輸出塔

第四章《數據迷霧》
Outer Wilds、The Witness
玩家靠觀察規律建立理解，舊資訊會改變新路徑
多次結果成為可走的塔群與橋，異常點可回到來源調查

第五章《封閉區》
Hardspace: Shipbreaker、Prey
先辨識危險源與連鎖失效，再動手處理
實體封鎖環境釋放路線，沿 source—pathway—receptor 建多層封閉
不加入戰鬥、危險生物或可操作的高風險配方
第六章《斷鏈》
Death Stranding、Satisfactory
路線、負重、基礎設施及最後一哩讓取得成為玩法
玩家親自送貨、改道、設 buffer，再承擔不同供應模型的代價
不用大量空地建設或長距離重複苦工填時數
第七章《門內的人》
Control、Prey、Hardspace: Shipbreaker
抽象機構具象成空間；保存現場、隔離、調查、恢復
資料路徑是可走建築；以 valve、audit spool 和門權限解題

The Talos Principle 2、Pacific Drive
角色價值衝突與系統準備共同影響結局
跟隨食物銀行流程、做 baseline、改版、公開試玩、決定 pilot／no-pilot

G. 製作順序：先證明核心好玩，再擴充內容
Vertical Slice 0｜序章＋第一章前半
先做 20–25 分鐘可玩的灰盒：Hub 選裝備、暴雨救援、Flow Lens 訊號追蹤、Tether 搬運、封閉探頭失效、返回流動站跑 control。這一片必須證明：移動、追蹤、物理操作及失效診斷在沒有長對白時仍有趣。
完成條件：
第三人稱移動、鏡頭、攀越和互動達到可測試品質。
Flow Lens 有方向、遮擋、電量及錯誤訊號，不是答案高亮器。
Tether 至少有重量、旋轉、碰撞和易損物四種狀態。
任務、字幕、聲音／形狀替代及寬鬆時間模式可用。
從失效到 control 修復的整段不出現卡牌、選項測驗或長篇講義。
Vertical Slice 1｜第三章完整
第二個切片驗證合成生物學是否能成為空間 puzzle：走進抽象 Cell City，診斷無輸入仍亮的輸出塔，完成最小修理、四個狀態測試及延遲觀察。
完成條件：
未上過合成生物學的玩家，離場時能以自己的話解釋 input—gate—output。
玩家不用背任何特定元件名稱也能定位兩個故障。
只憑一次亮起不能通關；必須跑至少一個合理 control 組合。
快速補丁和更換模組都可完成，但世界保留不同後果。
其後開發批次
第二章與第六章共用物料、物流、重量及路線系統，應同一批開發。
第四章與第七章共用 Flow Lens 的資料路徑顯示、版本和 audit 系統，應同一批開發。
第五章擴充危險隔離、失效模擬和撤離能力。
終章只在前七章狀態確實可讀取後製作，避免做成與歷程無關的最後選單。
最後才增加可選 Codex、收藏敘事和額外美術；不可讓它們延遲核心操作測試。

I. 本版交付邊界
這套主稿已提供完整場景次序、玩家目標、互動流程、必要對白、觸發條件、狀態、分支與章末世界結果，可直接進入灰盒和任務系統拆票。下一個製作文件應把每個 Scene 拆成：關卡 blockout、互動 prefab、任務 state machine、對白資料列、音效 cue、動畫需求、存檔欄位及 QA case。
本稿不將篇幅花在真實序列、濕實驗參數或專案特定元件記憶；教育價值來自玩家反覆操作可遷移的系統思維：看見流、驗證工具、保留失敗、限制主張、設計封閉、分配權限、讓受影響者改變方案，並在證據不足時有能力停下來。
